RETURNS DESK — ANDROID APP (GitHub Pages)
1. github.com -> New repository (e.g. returns-desk-app, Public) -> "uploading an existing file"
   -> drag ALL files of this folder -> Commit changes
2. Repo -> Settings -> Pages -> Source: Deploy from a branch -> main / (root) -> Save
3. Wait 1 minute -> link: https://<your-user>.github.io/returns-desk-app/
4. Paste that link in the app: Admin -> Mobile App -> "GitHub app link" -> Save
   (then the "Connect phone" QR opens this faster scanner)
5. Phones: open the link in Chrome -> ⋮ -> Install app -> allow Camera
Optional APK: pwabuilder.com -> paste link -> Android -> download -> share .apk
config.js already contains your Web App URL.
